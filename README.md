# Cars — интерактивный каталог автомобилей

Веб-приложение для подбора и изучения автомобилей. Пользователь может просматривать каталог, сужать выбор с помощью фильтров, открывать карточки с подробной информацией и отправлять заявку через форму обратной связи.

**[Открыть сайт](https://lyubov15.github.io/cars/)**

## Что реализовано

- **Каталог автомобилей** — динамическое отображение карточек с информацией об автомобилях.
- **Фильтрация** — поиск подходящих вариантов по нескольким параметрам.
- **Карточка автомобиля** — переход от общего каталога к подробному просмотру выбранной модели.
- **Модальное окно** — просмотр характеристик без необходимости покидать страницу каталога.
- **Форма обратной связи** — пользовательский сценарий отправки заявки.
- **Адаптивный интерфейс** — корректное отображение на мобильных устройствах, планшетах и десктопах.
- **Анимации интерфейса** — визуальная обратная связь при взаимодействии с элементами.

## Техническая реализация

Проект построен на Angular и TypeScript. Логика интерфейса разделена на отдельные области ответственности, а реактивные инструменты Angular и RxJS используются для организации взаимодействия с данными и пользовательскими действиями.

| Технология | Применение |
|---|---|
| **Angular 20** | архитектура клиентского приложения |
| **TypeScript** | типизированная логика приложения |
| **RxJS** | реактивная обработка потоков данных |
| **Angular Forms** | реализация и обработка форм |
| **Angular Router** | маршрутизация |
| **HTML5 / CSS3** | структура, оформление и адаптивность |

## Запуск проекта

Требуется установленный Node.js и npm.

```bash
git clone https://github.com/Lyubov15/cars.git
cd cars
npm install
npm start
```

После запуска приложение будет доступно по адресу:

```
http://localhost:4200
```

Сборка production-версии:

```bash
npm run build
```
