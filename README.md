Каталог автомобилей Cars

Фронтенд-приложение, моделирующее интерфейс сайта автодилера. Основное внимание уделено удобству пользователя, скорости работы и читаемому коду.
Проект демонстрирует навыки работы с DOM, организацией клиентской логики и построением адаптивных интерфейсов.

Демо: https://lyubov15.github.io/cars/

Функциональность проекта:
- адаптивная верстка под мобильные устройства и планшеты;
- фильтрация автомобилей по нескольким параметрам;
- динамическая отрисовка карточек автомобилей;
- модальное окно с подробной информацией об автомобиле;
- форма обратной связи / заявки;
- базовые анимации интерфейса;

Технологии, используемые в проекте:
- HTML5;
- CSS3;
- фреймворк Angular.
