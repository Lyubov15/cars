### 📖 О проекте

**Cars** — современный фронтенд-интерфейс сайта автодилера.  
Проект демонстрирует навыки работы с **Angular**, построением адаптивных интерфейсов, динамической отрисовкой данных и организацией клиентской логики.

Основной акцент сделан на:
- удобстве пользователя;
- скорости работы;
- чистом и читаемом коде.

---

### ✨ Функциональность

- **Полностью адаптивная вёрстка** (мобильные, планшеты, десктоп)
- **Фильтрация автомобилей** по нескольким параметрам
- **Динамическая отрисовка** карточек автомобилей
- **Модальное окно** с подробной информацией об автомобиле
- **Форма обратной связи** / заявки
- **Базовые анимации интерфейса**
