# Каталог автомобилей

Веб-приложение-каталог автомобилей с адаптивным интерфейсом, фильтрацией и просмотром подробной информации об автомобилях.
**Посмотреть сайт:** [https://lyubov15.github.io/cars/](https://lyubov15.github.io/cars/)

## Функциональность

- адаптивная вёрстка для мобильных устройств, планшетов и десктопов;
- фильтрация автомобилей по нескольким параметрам;
- динамическое отображение карточек автомобилей;
- просмотр подробной информации об автомобиле;
- модальное окно с характеристиками;
- форма обратной связи / заявки;
- базовые анимации интерфейса.

## Технологии

| Технология | Назначение |
|---|---|
| **Angular** | разработка клиентского приложения |
| **TypeScript** | типизация и реализация логики |
| **HTML5** | семантическая разметка |
| **CSS3** | стилизация и адаптивная вёрстка |
| **Angular Forms** | работа с формами |
| **Angular Router** | маршрутизация |
| **RxJS** | работа с асинхронными операциями |

## Запуск проекта локально

**1. Клонировать репозиторий**

```bash
git clone https://github.com/Lyubov15/cars.git
cd cars
```

**2. Установить зависимости**

```bash
npm install
```

**3. Запустить сервер**

```bash
npm start
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:4200
```
