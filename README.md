# Каталог автомобилей

**Посмотреть сайт:** [https://lyubov15.github.io/cars/](https://lyubov15.github.io/cars/)

---

## Функциональность

- Полностью адаптивная вёрстка (мобильные, планшеты, десктоп).
- Фильтрация автомобилей по нескольким параметрам.
- Динамическая отрисовка карточек автомобилей.
- Модальное окно с подробной информацией об автомобиле.
- Форма обратной связи / заявки.
- Базовые анимации интерфейса.

## Запуск проекта локально

### Требования

- Node.js 18+ 
- npm 9+

### Установка и запуск

**1. Клонировать репозиторий**

```bash
git clone https://github.com/Lyubov15/cars.git
cd cars
```

**2. Установить зависимости**

```bash
npm install
```

**3. Запустить сервер**

```bash
npm start
```

Приложение откроется по адресу http://localhost:4200.
